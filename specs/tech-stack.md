# Stack técnica

- **Interface:** React com TypeScript.
- **API:** Node.js com TypeScript.
- **Banco de dados:** SQLite, inicialmente.
- **Compatibilidade:** navegadores modernos e dispositivos móveis.

## Diretrizes

- Manter uma stack popular e confiável, conforme solicitado pela equipe de engenharia.
- Usar SQLite como banco inicial.
- Disponibilizar uma tela autenticada para cadastrar notícias, exibidas na página inicial.
- Apresentar somente os cursos técnicos indicados pela coordenação, incluindo matrizes curriculares, matérias e descrições.
- Permitir conteúdo curricular provisório em formato de mock enquanto necessário.
