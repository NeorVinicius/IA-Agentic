# Plano — ADM

## Grupo 1 — Estrutura

1. Criar a estrutura inicial do frontend React com TypeScript.
2. Criar a estrutura inicial da API Node.js com TypeScript.
3. Definir os pontos de integração entre frontend e API.

## Grupo 2 — Base técnica

4. Preparar configuração local e comandos de desenvolvimento.
5. Preparar a conexão da API com SQLite.
6. Adicionar uma rota simples de saúde da API.

## Grupo 3 — Verificação

7. Validar instalação, execução, build e verificações de tipos.
8. Documentar como configurar e executar a base ADM localmente.
