# Requisitos — ADM

## Escopo

Preparar a fundação técnica do módulo ADM para permitir o desenvolvimento incremental do site institucional. A entrega contempla a estrutura inicial da interface React com TypeScript, da API Node.js com TypeScript e a conexão inicial com SQLite.

Login, permissões e cadastro ou edição de notícias ficam fora deste escopo e devem ser tratados na fase F03 do roadmap.

## Decisões

- Usar React com TypeScript na interface.
- Usar Node.js com TypeScript na API.
- Usar SQLite como banco de dados inicial.
- Manter a fundação simples e preparada para evolução, sem antecipar funcionalidades administrativas.

## Contexto

A fase F01 do roadmap pede a estrutura do projeto e sua base técnica. A missão prioriza a captação de novos alunos e prevê notícias na página inicial, gerenciadas por usuários autenticados. Esta entrega prepara a base para esses próximos incrementos, sem implementar o catálogo ou o fluxo de notícias.
